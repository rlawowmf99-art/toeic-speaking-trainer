# 🎧 TOEIC Speaking 웹 연습기 v3 — AL(160~200) 고득점 특화 · 랜덤 문제은행 · AI 채점

학원 **조교가 먼저 풀어 보고, 수업에서 시연하고, 학생 피드백 자료로 바로 쓰는** 토익스피킹 실전 연습기입니다.
v3는 모든 모범답안·주요 표현·채점 프롬프트·셀프 체크를 **AL(160~200) 고득점 기준**으로 다시 썼습니다. 회화체 슬랭(gonna, wanna, a ton of …)은 전부 제거하고, 파트별 만점 공식(아래 2-1)을 그대로 따르는 시험용 문장만 수록했습니다.
**EiE 표현영어 · 고려대어학원**(Express in English) 테마로 브랜딩되어 있습니다. 고려대 크림슨(`#8B0029`)과 클래식 골드(`#B48A3E`)의 크림슨 아카데믹 팔레트, 방패형 인라인 SVG 엠블럼이 적용되어 있고, 모든 색은 설정의 "강조 색상"에서 다시 바꿀 수 있습니다.

파일 하나(`index.html`)로 끝나며, 설치·서버·로그인 없이 브라우저에서 바로 열립니다.

- 파일: `projects/toeic-speaking-trainer/index.html` (약 344KB, 단일 파일)
- 실행: 파일을 더블클릭 → 브라우저에서 시작 (오프라인에서도 동작)
- 외부 요청 0건(기본): 사진(장면)은 전부 인라인 SVG, 폰트는 시스템 폰트, CDN·이미지 파일 없음
- AI 기능을 켠 경우에만 OpenAI(또는 지정한 프록시)로 요청이 나갑니다.

## 2. 문제은행 구성

| 파트 | 문항 | 형식 | 준비 | 답변 | 수록 |
|---|---|---|---|---|---|
| Part 1 낭독 | Q1–Q2 | Read a Text Aloud | 45초 | 45초 | **지문 10종** |
| Part 2 사진 묘사 | Q3–Q4 | Describe a Picture | 45초 | 30초 | **SVG 장면 8종** |
| Part 3 질문 응답 | Q5–Q7 | Respond to Questions | 3초 | 15/15/30초 | **인터뷰 10세트(30문항)** |
| Part 4 정보 활용 | Q8–Q10 | Respond Using Information Provided | 표 읽기 45초 + 3초 | 15/15/30초 | **정보표 7종(21문항)** |
| Part 5 의견 제시 | Q11 | Express an Opinion | 45초 | 60초 | **의견 10종** |

- **Part 1 지문**: 사내 피크닉 공지, 매장 공사 안내, 시티투어 방송, 업무 음성 메시지, 교통·날씨 방송, 제품 시연 안내, 미술관 안내, 신입 오리엔테이션, 호텔 체크아웃, 자원봉사 모집 (84–104단어)
- **Part 2 장면**: 회의실 발표, 야외 카페, 공항 체크인, 과일 가판대, **공원 조깅로**, **도서관 열람실**, **마트 진열대**, **오피스(코워킹)**
- **Part 3 인터뷰**: 서점 아르바이트 면접, 자전거 대여 전화, 일상 루틴, 쇼핑 습관, 재택근무 정책, 단체 저녁 예약, 주말 여행 상담, 헬스장 상담, 스마트폰 습관, 지역 행사 이야기
- **Part 4 정보표**: 컨퍼런스 센터 요금, 호텔 주말 액티비티, 공방 클래스 요금, 박물관 투어 일정, 공항 셔틀 시간표, 피트니스 수업 시간표, 컨퍼런스 첫날 일정
- **Part 5 의견**: 재택근무, 혼자 여행, 업무용 AI, 대중교통 투자, 온라인 쇼핑, 청소년 스마트폰, 회사 복장, 주 4일 근무, 일회용 플라스틱, 학위 vs 능력

모든 문항에 **모범답안(AL 시험용 문장) · 주요 표현(영→한) · 셀프 체크 · 전략 팁**이 붙어 있습니다.

### 2-1. 파트별 AL 고득점 공식 (모든 모범답안이 이 틀을 따릅니다)

| 파트 | 공식 | 답안에 반드시 들어가는 것 |
|---|---|---|
| Part 1 낭독 | 의미 단위 끊기 → 내용어 강세 → 문장 끝 억양 | 낭독 스크립트(`/` 쉼, **굵게** 강세, ↘ 내림) + 톤·억양·발음 포인트 해설 |
| Part 2 사진 | ① 전체 장면 → ② 전경 주인공(현재진행형) → ③ 배경·세부 → ④ 분위기 추측 | `In the foreground`, `is standing/holding`, `It looks as if ~` |
| Part 3 인터뷰 | 첫 문장 즉답 → 세부·이유 (30초는 근거 2개) | `I would ~`, `because/since`, 구체적 숫자·경험 |
| Part 4 정보표 | 출처 밝히기 → 요구 항목 전부 → 정확한 수치 → note | `According to the table`, 계산 과정, 표에 없는 숫자 금지 |
| Part 5 의견 | 주장 → 이유①+예시 → 이유②+예시 → 반대 인정 → 결론 | `I strongly believe`, `First of all … For example`, `For these reasons` |

이 공식은 앱 홈의 **📐 만점 템플릿 가이드** 버튼과 모범답안 드로어의 **Part N 고득점 공식** 버튼에서 그대로 볼 수 있습니다(파트별 단계·필수 표현·감점 습관·예시 문장).

## 3. 사용법

### 3-1. 모의고사 (기본: 랜덤)
1. 홈에서 **🎲 랜덤 실전 모의고사**(기본 선택) 또는 Set 1·2를 고릅니다.
2. `랜덤 모의고사 시작` → 마이크 권한 허용 → Q1부터 Q11까지 실전과 같은 순서·시간으로 진행.
3. 답변이 끝나면 **AI 채점** 버튼 → 세 기준 점수, 등급, **AL 고득점 교정 문장**과 ‘AL까지 남은 격차’ 확인.
4. 결과 화면에서 문항별 녹음·자가평가 + **모든 답변 채점하기**(한 번에 채점).

- 랜덤 모드는 **최근 2회 세션에서 쓴 문제를 제외**하고 뽑습니다(지문 10·사진 8·인터뷰 10·표 7·의견 10이라 연속 회차에서 겹치지 않습니다).
- 결과 화면의 **🎲 새 조합으로 한 번 더**를 누르면 바로 다음 세트가 나옵니다.
- 진행 중 **다시 시작**(R) 버튼으로 같은 세션을 처음부터 다시 시작할 수 있습니다(확인창 1회).

### 3-2. 파트별 연습
홈 아래 파트 카드 → 해당 파트만 연습. 랜덤 모드에서는 파트별로도 새 문제를 뽑습니다.
(Part 1·2는 2문항, Part 3·4는 3문항, Part 5는 1문항 — 실제 시험 번호 Q1·Q3·Q5·Q8·Q11을 유지)

### 3-3. 조교용 기능
- **모범답안 복사**: 모범답안 드로어의 `모범답안 복사` → 수업 자료·슬라이드에 바로 붙여넣기
- **모범답안 듣기**: 영어 TTS로 읽어 주어 시연·섀도잉에 사용
- **채점 기준 카드**: 홈 사이드의 “조교용 빠른 안내”에 3개 기준과 환산 규칙 요약
- **📐 만점 템플릿 가이드**: 홈 카드의 버튼(또는 모범답안 드로어의 `Part N 고득점 공식`) → 파트별 공식·필수 표현·감점 습관·예시 문장을 판서용으로 바로 확인, `이 파트 연습하기`로 즉시 드릴 시작
- **빠른 초기화**: `다시 시작`(R) · 결과 화면의 `새 조합으로 한 번 더`

### 3-4. 단축키
`Space` 일시정지/계속 · `N` 다음 문항 · `M` 모범답안 · `R` 세션 다시 시작 · `Esc` 닫기

## 4. AI 채점

### 4-1. 켜는 방법
앱 오른쪽 위 **설정** → **OpenAI API 키** 입력(또는 **프록시 URL**) → 저장.
키가 없으면 자동으로 **로컬 분석**만 사용합니다(기능 제한 없이 동작, 점수만 지표 기반).

| 설정 | 설명 |
|---|---|
| OpenAI API 키 | `sk-...`. 이 브라우저(localStorage)에만 저장됩니다. |
| 프록시 엔드포인트 URL | 입력 시 키 없이 이 주소로 요청. 서버가 키를 숨기는 운영용. |
| 모델 | 기본 `gpt-4o-mini`. 음성 인식은 `whisper-1` 고정. |

프록시를 쓰면 브라우저는 `Authorization` 헤더를 보내지 않고, `POST {proxy}/chat/completions`, `POST {proxy}/audio/transcriptions` 두 경로만 호출합니다. 서버가 OpenAI로 중계하면 됩니다.

### 4-2. 채점 방식
1. 녹음이 있으면 `whisper-1`로 **전사**합니다.
2. 녹음이 없거나 인식 실패 시 → 실시간 받아쓰기 텍스트 → 직접 입력한 텍스트 순으로 대체.
3. **AL(160~200) 기준 3축**으로 1.0–5.0(0.5 단위) 채점:

| 기준 | 보는 것 |
|---|---|
| 발음·억양·강세 (Pronunciation · Intonation) | 끊어 읽기, 내용어 강세, 문장 끝 억양, 속도·머뭇거림 (텍스트 기반 한계는 결과에 명시) |
| 문법·어휘·다양성 (Grammar · Vocabulary) | 시제·수 일치, 전치사, 복문·관계절·분사구, 정확한 연어. 슬랭·필러는 감점 |
| 내용·과제·논리 (Content · Task · Structure) | 두괄식 결론, 근거 2개+예시, 표 항목 누락·수치 오류 여부 |

4. 평균을 **Lv.1–8 / NM·IM1–3·IH·AL** 구간으로 환산(앱 내 `LEVEL_GUIDE` 기준).
5. **AL 고득점 교정**: 학습자가 실제로 말한 문장 2–3개를 골라 **시험용 고득점 문장**으로 바꾸고, 어떤 채점 기준에서 왜 점수가 오르는지(예: “두괄식 결론 + 구체적 이유 연결 → 논리·과제 수행”) 한국어로 설명.
6. **AL까지 남은 격차**: 이 답변이 AL 구간에 못 미치는 이유를 한 문장으로 제시(프롬프트의 `benchmark` 필드).
7. **잘한 점 1–2개 / 고칠 점 1–2개**를 한국어로 제시.

### 4-3. 로컬 기본 분석 (키 없이)
녹음·텍스트에서 다음을 계산해 같은 3축 점수를 냅니다.

- 단어 수, 답변 시간, **WPM(분당 단어 수)**
- **필러 비율**(um, uh, you know, I mean …)
- **침묵 비율**(녹음을 실제로 디코딩해 20ms 프레임 에너지로 측정; 디코딩 불가 시 `–`)
- **키워드 커버리지**(지문·모범답안·주요 표현의 핵심 어휘 대비 사용률)
- 문장 길이, 연결어 수, 어휘 반복률

로컬 점수는 **발음의 실제 음향 평가가 아닙니다.** 절대 점수보다 경향(속도·분량·구조)을 보는 용도입니다.

### 4-4. 비용·주의
- AI 채점 1회 = Whisper 전사 1회 + 채팅 1회. `gpt-4o-mini` 기준 문항당 수 원 수준입니다(사용량·환율에 따라 변동).
- “모든 답변 채점하기”는 **답변한 문항 수만큼** 호출합니다(11문항이면 최대 22회).
- 실패(401/429/네트워크) 시 **로컬 분석으로 자동 대체**하고 이유를 결과 상단에 표시합니다.

## 5. ✨ AI 새 문제 생성

홈의 **✨ AI 새 문제 생성 → 새 문제 만들기**:
- 지문 2 · 사진 2 · 인터뷰 3 · 정보표 3 · 의견 1 = **11문항 세트를 새로 생성**해 바로 시작합니다.
- 사진은 앱이 가진 8개 SVG 장면 중에서 고르게 되어 있어(없는 장면은 자동 대체) 그림이 깨지지 않습니다.
- 생성 결과는 그 세션에만 유지됩니다(새로고침 시 사라짐). 다시 쓰려면 결과 화면의 **이 세션 다시 하기**.
- 생성 프롬프트도 같은 AL 공식을 요구합니다: 낭독은 `chunks`(끊어 읽기 스크립트)까지, 사진은 ①~④ 4단, 인터뷰·표는 15/15/30초 구조, 의견은 4문단(주장·이유1+예시·이유2+예시·결론), 그리고 **표에 없는 숫자 생성 금지**.
- 실패 시 토스트로 이유를 보여 주고 기존 세트는 그대로 둡니다.

- **녹음 파일**은 브라우저 메모리에만 있고, 기본 상태에서는 서버로 전송되지 않습니다. 탭을 닫으면 사라집니다.
- **AI 채점을 켠 경우**, 해당 문항의 **녹음 오디오가 OpenAI(또는 지정한 프록시)로 전송**됩니다. 학생에게 사용할 때는 이 점을 먼저 알리고 동의를 받으세요.
- **API 키는 localStorage에 저장**됩니다. 공용 PC에서는 키를 저장하지 말고, 운영 환경에서는 **프록시 URL**을 쓰세요.
- 실시간 받아쓰기는 브라우저 제조사(예: Google)의 음성 인식 서비스를 사용합니다. 원치 않으면 설정에서 끄면 됩니다.
- 모범답안 복사는 브라우저 클립보드 권한이 필요합니다(`file://`에서는 `execCommand`로 대체).

## 7. 공유·배포 (조교 배포용)

### 방법 A — 파일 그대로 (가장 간단)
`index.html` 하나를 카카오톡·메일·USB로 전달합니다. 받은 사람이 더블클릭하면 끝. 오프라인에서도 동작합니다.
(마이크가 막히는 브라우저가 있으면 로컬 서버로 열기: `python3 -m http.server`)

### 방법 B — GitHub Pages (링크로 배포)
1. 저장소에 `index.html`을 올립니다(파일명 그대로).
2. Settings → Pages → Branch: `main` / root 선택 → 저장.
3. `https://<아이디>.github.io/<저장소>/` 링크를 조교에게 공유.
- HTTPS라서 클립보드·마이크 권한이 더 매끄럽게 동작합니다.

### AI를 링크 배포와 함께 쓸 때
키를 HTML에 넣지 마세요. **프록시**를 두고(Cloudflare Worker·Vercel·사내 서버 등) 설정 화면에 프록시 URL만 배포합니다.
프록시는 아래 두 요청을 OpenAI로 전달하면 됩니다.

```
POST {proxy}/audio/transcriptions   (multipart/form-data → api.openai.com/v1/audio/transcriptions)
POST {proxy}/chat/completions      (application/json → api.openai.com/v1/chat/completions)
```

## 8. 파일 구조

단일 HTML 안에 세 개의 `<script>` 블록:

1. **SCENES** — 인라인 SVG 장면 8종(사람 그리기 헬퍼 `fig()` 포함)
2. **CONTENT / BANK** — 고정 세트 `SETS`, 확장 문제은행 `BANK`, 조합기 `composeSet()`, 랜덤 선택 `randomSelection()`, AI 세트 변환 `setFromAi()`, `LEVEL_GUIDE`
3. **APP** — 화면·타이머·녹음·TTS·STT, 랜덤/최근기록, AI 채점·로컬 분석·결과 모달

브라우저 저장 키:

| 키 | 내용 |
|---|---|
| `toeiclab.settings.v1` | 옵션 + API 키/프록시/모델 |
| `toeiclab.brand.v1` | 학원 이름·슬로건·로고 글자·색상 |
| `toeiclab.recent.v1` | 최근 세션별 사용 문항 id(반복 방지) |
| `toeiclab.scorelog.v1` | 최근 채점 요약 20건(디버그용) |

문항 추가는 `BANK.read / picture / interview / chart / opinion`에 객체를 push 하면 됩니다. 자세한 필드는 코드 상단의 기존 항목을 참고하세요.

- Part 1 항목은 `passage`(시험에 보이는 원문)와 `chunks`(낭독 스크립트: `/` 쉼, `<b>` 강세, ↘ 내림)를 함께 가집니다. `chunks`가 없으면 드로어에 낭독 스크립트가 표시되지 않습니다.
- `model` 안에서 `<b>`는 강조로 렌더링됩니다(그 외 태그는 이스케이프). Part 2~5는 `① ② ③` 라벨로 공식 단계를 표시합니다.
- `MAX_TEMPLATES`(만점 공식)와 `RUBRICS`(셀프 체크)도 같은 파일 안에 있으니, 문항을 늘리면 함께 손보세요.

검증용으로 `window.TOEIC`(문제은행·조합기·로컬 채점 함수)를 노출해 두었습니다. 사용자 화면에는 영향이 없습니다.

## 10. 알려진 한계

- AI 채점의 “발음”은 텍스트·유창성 단서 기반입니다. 실제 음향 발음 평가가 아닙니다.
- 자동 환산 레벨은 학습용 참고치이며 실제 토익스피킹 점수가 아닙니다.
- 녹음은 세션 메모리에만 남습니다(새로고침 시 사라짐). 보관이 필요하면 결과 화면에서 바로 확인하세요.
- 표 읽기 45초는 Part 4 첫 문항에서만 진행됩니다(실제 시험과 동일).
- iOS Safari는 화면 잠금 시 녹음이 중단될 수 있고, 실시간 받아쓰기는 Chrome·Edge만 지원합니다(녹음·타이머는 정상).
- AI 새 문제 생성은 모델 응답 품질에 따라 문항이 어색할 수 있습니다. 생성 후 모범답안을 한 번 확인하세요.
